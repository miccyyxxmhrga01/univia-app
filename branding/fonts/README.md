# Poppins

Poppins Regular, SemiBold, and Bold are bundled from the official Google Fonts repository:

https://github.com/google/fonts/tree/main/ofl/poppins

The SIL Open Font License is included in `Poppins-OFL.txt`. The fonts are packaged locally in `app/src/main/res/font`; the app makes no font network requests.
